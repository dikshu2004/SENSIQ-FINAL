# SensiQ — Inclusive E-Learning Platform

SensiQ is a full-stack e-learning platform designed to make learning more accessible for **Deaf, Mute, and Visually Impaired learners**.

It combines online courses, progress tracking, assistive communication tools, Indian Sign Language resources, and AI-powered features in one platform.

## Features

* 🎓 Inclusive courses and lesson-based learning
* 📊 Course progress tracking and resume support
* 🎙️ Speech-to-Text using Gemini AI
* 🔊 Text-to-Speech using the Web Speech API
* 🤟 Indian Sign Language (ISL) learning resources
* 💬 AI chatbot for platform and course assistance
* ♿ High-contrast mode and keyboard shortcuts
* 🎤 Voice navigation and screen narration
* 🔐 User authentication and session management
* 📧 Contact form and email support
